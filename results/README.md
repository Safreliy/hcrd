# Generated results

This directory contains reproducible experiment outputs. CSV and JSON files
are generated by scripts under `experiments/` and should not be hand-edited.

Modern external controls are stored in `ceemdan_confirmation_e2`,
`iterative_filtering_e3`, and `qtdb_modern_r3`.  Their corresponding frozen
protocols are under `docs/`; R3 is post-lock exploratory by construction.

`qtdb_multilevel_m1` and `qtdb_hybrid_m2` are post-R2 application-development
studies. `xjtu_x1`, `xjtu_x2*`, and `xjtu_x3*` contain the predefined XJTU-SY
RUL stages. `xjtu_indicator_analysis` is exploratory.

`pronostia_h1` is the independently specified transfer of the XJTU-selected
polygon-mass coordinate and contains the bearing-level trendability results.
