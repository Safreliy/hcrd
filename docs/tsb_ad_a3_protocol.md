# A3: learned anomaly detection on signed HCRD components

Status before execution: **development protocol; official evaluation sealed**.

## Question

Does the full signed HCRD decomposition provide a useful learned
representation when polygon mass is treated as supplementary information,
rather than as the only feature?

## Representation

For every time sample, the primary vector contains the first eight signed HCRD
details `(d_1, ..., d_8)`. Fixed ablations use their absolute values, the
concatenation of signed and absolute details, or a full vector that additionally
contains raw value, raw first difference, total polygon-mass density, scale
barycentre, and scale entropy.

An Isolation Forest with 128 trees and at most 512 training samples is fit only
on the normal prefix encoded in each official TSB-AD filename. It receives no
labels. Hyperparameters are fixed for every file and representation. The A1
direct score and equal-rank fusions between it and each forest score are
included, giving eleven candidates generated by one public function.

## Development and freeze

- Data: official 48-series TSB-AD-U tuning split.
- Primary metric: mean exact VUS-PR at the official 250 thresholds.
- Ties: median VUS-PR, then lexical candidate name.
- The selected candidate, full metrics, implementation hashes, A1/A2 freeze
  hashes, and data hashes are written before the first evaluation execution.

## Confirmation interpretation

A signed-component or signed+area win over the area-only A1 ablation would
support the user's hypothesis that the decomposition is the main practical
object and polygon mass is auxiliary. Failure would show that a generic
pointwise forest does not exploit the hierarchy sufficiently; it would not
falsify sequence learners or task-specific supervised uses of the components.
